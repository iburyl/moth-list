{% comment %} Shared zoom/pan/navigation logic for the image viewer. Exposes a small API on ``window.Viewer`` and dispatches a ``viewer:load`` event on ``document`` whenever the stage image is (re)fitted. Pages register their overlay renderer via that event, e.g.:: document.addEventListener("viewer:load", renderOverlay); if (window.Viewer && window.Viewer.ready) renderOverlay(); API: Viewer.overlay -> the #overlay element to draw markers into Viewer.pointer -> { x, y, inside } latest pointer position (client px) Viewer.clientToNorm(cx, cy) -> { x, y } normalized image coords (may be <0 or >1) Viewer.refit() -> re-fit the image to the viewer Viewer.setShiftDragHandler(h) -> route Shift+drag to h.start/move/end(norm) (norm = clientToNorm result) instead of panning Viewer.ready -> true once the image has loaded and been fitted {% endcomment %}
